## 🎓 COMMAND SYNTAX RULES

**Always use:**
```
✅ "Sophia, [ACTION] [DETAILS]"
✅ "Sophia, [ACTION] [DETAILS] now"
✅ "Sophia, [ACTION] for [TIMEFRAME]"
```

**Never:**
```
❌ "Fix it" (too vague)
❌ "Make it faster" (unclear)
❌ "Do something" (non-specific)
```

**Sophia asks for clarification:**
```
SOPHIA: "Multiple options available:
  A) Quick fix
  B) Thorough fix
Which would you prefer?"

ULTRON: "Option B"
SOPHIA: "Understood. Proceeding..."
```
