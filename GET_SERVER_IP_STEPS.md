# 🎯 STEP-BY-STEP: HOW TO GET YOUR SERVER IP ADDRESS

**Time**: 5-10 minutes

## ✅ METHOD 1: DigitalOcean (EASIEST - RECOMMENDED)

### **STEP 1: Go to DigitalOcean**
```
1. Open: https://www.digitalocean.com/
2. You should see the homepage
```

### **STEP 2: Click "Sign Up"**
```
Location: Top right corner
Look for: "Sign Up" button
Color: Usually blue
```

### **STEP 3: Create Account**
```
Fill in:
  - Email: (your email)
  - Password: (create strong password)
  - Full Name: (your name)

Click: "Sign Up"
```

### **STEP 4: Verify Email**
```
1. Check your email inbox
2. Look for: "DigitalOcean verification email"
3. Click: Verification link
4. You're verified!
```

### **STEP 5: Add Payment Method**
```
1. You'll be asked for payment
2. Enter: Credit card details
3. Click: "Add Payment Method"
Note: You get $200 free credit (60 days)
```

### **STEP 6: Create Your Server (Droplet)**
```
1. Click: "Create" button (top left)
2. Select: "Droplets"
3. You see options now
```

### **STEP 7: Choose Operating System**
```
Look for: "Choose an image"
Select: 
  - Ubuntu
  - Version: 20.04 LTS x64
  
Click: Ubuntu 20.04 LTS
```

### **STEP 8: Choose Size (Plan)**
```
Look for: "Choose a size"
Select: 
  - $5/month option (1GB RAM, 25GB SSD)
  
This is perfect for Realtor Vikkas
```

### **STEP 9: Choose Region**
```
Look for: "Choose a region"

If you're in India:
  Select: Bangalore (fastest)
  
If you're elsewhere:
  Select: Singapore or closest region
  
Click: Your choice
```

### **STEP 10: Authentication Method**
```
Look for: "Select authentication method"

Choose: "Password"
  (Easier than SSH keys)

Create Password:
  - Must be strong
  - Must be 8+ characters
  - Example: MyServer@2024!

IMPORTANT: Write down this password!
```

### **STEP 11: Choose Hostname**
```
Look for: "Choose a hostname"
Enter: realtor-vikkas
(This is just the server name)
```

### **STEP 12: Create!**
```
Click: "Create Droplet" button
Wait: 30-60 seconds for server to start
```

### **STEP 13: FIND YOUR IP ADDRESS** ⭐
```
After creation, you'll see your droplet listed
Look for: "IP Address" column
It shows something like: 45.33.45.123

COPY THIS IP ADDRESS!
This is what you need!
```

## ✅ TROUBLESHOOTING

**Q: I don't see the IP address?**
A: Wait 1-2 minutes, then refresh the page. It appears after the server starts.

**Q: Payment declined?**
A: Try another card, or use AWS free trial instead.

**Q: Can't verify email?**
A: Check spam folder. If still missing, use "Resend verification" button.

**Q: Forgot password?**
A: Click "Forgot password" on login page, get reset link via email.

**Q: Server shows "New" status?**
A: That's normal! Wait 1-2 minutes for it to boot. Then IP appears.
